# 问法比证据量重要 —— 2026-09-10 实测

## 1. 之前报的「加帧 +4.2 点」是位置偏置

`16f_nocurve` 那一轮把 `n_a` 留空,`compare()` 的提前返回把交换检查**静默跳过**了。
分层一看就露馅:

```
16f_nocurve(交换检查被跳过)
  强偏好 21 对   61.9%
  弱偏好 51 对   60.8%     ← 难度轴上完全平的
  选A率 74%  vs  人评 A 侧 37%
```

真判官的准确率应当随人类一致性强度上升。这条是平的,因为它在按位置答题。
`compare()` 现在拿不到交换方式就返回 `ok=False`——静默跳过是位置偏置的判官冒充
正常判官的唯一途径,堵死。

## 2. 打开交换检查后,帧数对准确率没有可读出的影响

dev 100 对,gemma-4-31b,`aligned_pair` 按行对切成多张图(每帧像素数与 n 无关):

| 帧数 | 强偏好 | 弱偏好 | 合计方向 | 顺序翻转 | 选A率(人评 37%) |
|---|---|---|---|---|---|
| 8  | 63.6% (11/21) | 41.7% (24/51) | 48.6% (n=35) | 53% | 25% |
| 16 | 66.7%  (9/21) | 44.4% (18/51) | 51.9% (n=27) | 65% | 21% |
| 32 | 50.0% (14/21) | 63.0% (27/51) | 58.5% (n=41) | 38% | 33% |

可判定的强偏好只有 9–14 对,±15 点的置信区间,**三档之间读不出差别**;
32 帧那一档的形状还是反的(弱偏好高于强偏好),更像噪声。

**唯一稳定的效应是位置偏置随帧数下降**:翻转率 53% → 65% → 38%,选A率 25% → 21% → 33%
(人评 37%)。32 帧那轮先后跑了两次(一次赶上本机进程数被打爆、26 次静默解码失败,一次干净),
58.5% / 61.5%,翻转率都是 38%——这一项是可复现的。

结论:**不要再在「哪段更好」这个问法上调参数**。一半的判断经不起换边,
调帧数是在给一个信息量接近零的判断加分辨率。

## 3. 能力探针:模型没问题,问题有问题

9 个探针第一次真跑(建好之后一直没执行过),gemma-4-31b 全过,等级 strong:

```
schema 一次通过 · 最多 48 图 · 计数 3/3 · 接地 IoU 0.86
时序读取 6/6 · 埋在 1300 字中段的约束照做 · 纯色图上报 0 条缺陷
自洽率 100%(温度 0.8 下 5 次采样全同)→ 投票无用
最小可判读尺寸 448px
```

顺带用带标号的格子测了拼图本身:8 格并排时模型仍能寻址到指定格并数对点数,
所以**拼图布局不是瓶颈**。

模型的感知、指令遵循、以及「不无中生有」都在。坏的是问法——
「哪段运动更好」是个它没有校准先验的审美判断,而计数、定位、时序、不编造
是**缺陷检测**的能力。

## 4. 归一化把跨视频信息全删了

`compute_maps` 返回前对每个信号做 exceedance 归一化,那是**视频内**的秩变换。
200 条视频上每个归一化信号的 p99 全部等于 1.989,一位不差——固定大小的图的秩统计量
本来就是常数。

**建立在归一化图上的分数能排一条视频内部的时刻,永远说不出哪条视频更差。**
后者恰好是 point-wise 打分的定义。已加 `raw=True`。

## 5. 单个测量量在强偏好上打到 71–73%

dev 100 对,不用 VLM,每个量单独排序(相对差 <5% 视为不表态):

| 信号 | 强偏好 | 弱偏好 |
|---|---|---|
| freeze | **73.3%** (11/15) | 42.9% (18/42) |
| jerk | **71.4%** (15/21) | 49.0% (24/49) |
| softness | 64.7% (11/17) | 63.6% (28/44) |
| fused_max | 64.7% (11/17) | 54.3% (25/46) |
| flow_mean | 52.4% (11/21) | 60.4% (29/48) |
| flow_anomaly | 47.6% (10/21) | 41.7% (20/48) |
| luma_jump | 42.9% (9/21) | 46.9% (23/49) |

一个数就比 VLM 的直接比较高一大截,零成本、结构上不可能有位置偏置。
弱偏好一片随机——那批是标注员自己也几乎分不开的对,天花板可能不在模型这边。
