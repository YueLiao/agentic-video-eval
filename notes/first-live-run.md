# 第一次真实 VLM 运行:一次静默失败,以及从中得到的三条结论

配置:gemma-4-31b-it 本地 vLLM,`v7_e031`(陶轮拉坯,双手为画面主体)× 3 个生成模型 ×
8 个 skill。条件编译、路由、全部 skill、反证、打分全流程。
消耗 1.02M input / 18.4K output token,848 张图。

## 结果:表面全 10.00,实际撤回率 100%

29 个 aspect 在三个模型上**全部满分**,总分 10.00/10.00/10.00。

看起来是"三个模型都完美"。实际上是:**10 条 finding 全部被反证环节撤回。**

这是这套系统能产出的最坏输出——一份看起来干净的报告来自一条坏掉的流水线。
它比崩溃危险得多,因为没有任何东西提示你不要相信它。

## 结论一:核心论点成立,448px 裁剪确实让 VLM 看见了手指问题

三个模型的 `human_integrity` 都在放大裁剪里报出了**具体的、空间定位的**手部畸形:

> "在 E20 的放大裁剪图中,人物左手在接触陶土时,手指结构崩坏,多根手指粘连在一起形成团块"
> "f111 帧中出现了一根违反生物结构的细长突起"

这些不是套话。整个架构押在"分辨率是瓶颈而非能力"上,这一条现在有证据了。

## 结论二:agent loop 的行为合理

`human_integrity` 选了 `zoom_hands` → `zoom_hands` → `zoom_face`;
`static_integrity` 走了 `next_sheet` → `next_sheet` → `zoom`,正是设计的粗筛→确认级联。
8 个 skill 全部跑完,无崩溃、无死循环、无非法动作。

条件编译也成功:gemma 从英文 prompt 拆出 7 条中文要求,全部合理。
**但漏掉了 "camera fixed"** —— 它出现在句尾、与 "Workshop light" 并列成环境描述,
读起来不像指令。system prompt 里明写了"有运镜描述必须产出 camera 要求"仍然没用。
说明**指令性约束靠 prompt 说服不可靠,需要代码层的确定性兜底。**

## 结论三:反证环节的举证责任设反了

撤回理由几乎全是同一个形状——提出一个替代解释就完事:

| 指控 | 撤回理由 |
|---|---|
| 手指粘连成团块 | "覆盖着厚厚的白色泥浆,泥浆遮挡导致界限模糊" |
| 手部结构崩坏 | "快速运动产生的自然运动模糊" |
| 粘土凭空拉丝 | "极湿粘土分离时的正常物理表现" |

**每个解释单独看都成立。** 问题是我的 prompt 写了"存疑一律 retract",
而对任何视觉现象,一个足够聪明的模型**总能**构造出无罪解释。
这等于把举证标准设成"必须排除一切其他可能",没有任何指控能通过。

更糟的是它形成了闭环:`DO_NOT_PENALIZE` 教模型"运动模糊是正常的",
反证方就用运动模糊解释掉一切;rubric 的 `confusable` 字段教它"泥浆遮挡不算畸形",
它就用泥浆解释掉一切。**为降低假阳性建的两个机制,被反证方当成了万能免罪符。**

另外:**所有 finding 的 confidence 都是 0.5**,模型完全没有在区分把握程度。
这让任何基于置信度的分流都失效。

## 已做的修复

**1. 撤回率越界即标记不可信。** 撤回率 >75% 或 <5%(且指控数≥4)时,
整次运行打上警告并在报告顶部显示。100% 撤回不再能静默产出满分。
零撤回同样报警——那意味着反证形同虚设。

**2. 举证责任转移到替代解释身上。** 反证方不再问"能否解释掉",而必须**验证**
自己的替代解释与证据是否一致:说是运动模糊,就得在慢速帧上找到该部位是清晰的;
说是泥浆遮挡,就得说明为什么结构在覆盖下仍然违反解剖。
**提出替代解释但给不出支持证据的,不予撤回**(代码强制,不只是 prompt 要求)。

**3. 增加 `insufficient` 档。** 原来只有 uphold/retract 两档,
逼着模型把"看不清"归入撤回。现在证据不足是独立结论:保留但降权,
既不算证实也不算推翻。

## 仍未解决

- **同一个模型既当指控方又当反证方**,等于让它自己推翻自己。跨模型反证应该更强,
  但需要第二个 endpoint 才能验证。
- **confidence 恒为 0.5**,需要在 prompt 里给出校准锚点,或改用离散档位。
- **条件编译漏运镜**,需要确定性兜底。
- 本次只有 1 条 prompt × 3 模型,**任何区分度结论都不成立**。收拢名单仍然缺数据。

## 修复后的重跑

同样三条视频,只有反证环节重跑(前序调用命中缓存)。

```
                  wan22_14b  cosmos3_super  cosmos3_nano
人手结构               6.50       6.50          3.00
物体恒存              10.00      10.00          6.50
动作自然度             10.00      10.00          6.50
总分                  8.15       8.15          6.17

撤回率                 67%        33%            0%
可信                    ✓          ✓        ✗ (零撤回报警)
```

撤回率从 100% 降到 0–67%,且第一次出现跨模型差异。撤回时会引用具体帧号验证
自己的替代解释,而不再是提出解释就算数:

> "观察 t0000 到 t0034 的连续帧(E02),手指的整体轮廓是连贯的…  [依据:E20 (t0…)]"

**但这仍是 1 条 prompt × 3 模型,是观察不是结论。**

## 新暴露的问题

**同一缺陷在不同 skill 下结论相反。** `wan22_14b` 的手部畸形在 `static_integrity`
存活、在 `human_integrity` 被撤回——同一条视频、同一个部位、同一个模型。
说明反证结果对**证据呈现方式**高度敏感(粗筛的分块图 vs 手部专门裁剪),
不是一个稳定的判定。这比撤回率过高更麻烦,因为它无法靠调阈值解决。

**撤回率方差过大。** 0% / 33% / 67% 跨越了整个可信区间。`cosmos3_nano` 的
4 条指控一条没被挑战,反证在那一侧又太松。单一阈值可能本就不适合按视频判定,
应当按**跨视频的分布**来监控。
